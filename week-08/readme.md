## What I did
- Thought about how accessible the project was for non-technical users
- IBM specifically asked for a novice-friendly version students could use
- Designed the Novice Wrapper concept — 3 plain English variables to configure the car
- Planned the terminal dashboard layout for main.py
## Novice Wrapper design
- Student edits 3 lines max:
  - `SPEED_STYLE` — cautious / normal / aggressive
  - `CORNER_STYLE` — safe / balanced / racer
  - `DAMAGE_BEHAVIOUR` — ignore / careful / retire
- No TORCS knowledge needed at all
